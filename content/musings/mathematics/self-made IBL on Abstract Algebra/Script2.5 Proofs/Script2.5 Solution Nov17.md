
## Order of a Permutation

**Theorem 2.5.23.** If $\sigma = \sigma_1 \sigma_2 \cdots \sigma_r$ is a product of disjoint cycles of lengths $k_1, k_2, \ldots, k_r$, then:
$$|\sigma| = \operatorname{lcm}(k_1, k_2, \ldots, k_r).$$
$Proof:$
By **Theorem 2.5.22.** The order of a cycle $\sigma=(a_1 \ a_2 \ \cdots \ a_k)$ is $k$.
For $\sigma_{i}$ with length $k_{i}$ and thus order $k_{i}$,  $$\sigma_{i}^{tk_{i}}=e,t\in \mathbb{Z}$$On the other hand, since $\sigma_{i}$ are disjoint, other permutations would not affect the elements permutated by $\sigma_{i}$.
Formally that is, consider $a$ (only) permutated by $\sigma_{i}$, we have$$\sigma(a)=\sigma_{i}(a)$$
Therefore, the order of $\sigma$ has to be the smallest multiple of all $k_{i}$ to ensure the identity of all elements.
Thus, by the definition of order and $lcm$, $$|\sigma| = \operatorname{lcm}(k_1, k_2, \ldots, k_r).$$
**Example 2.5.24.** The permutation $\sigma = (1 \ 2 \ 3)(4 \ 5)$ has order $\operatorname{lcm}(3, 2) = 6$.

**Exercise 2.5.25.** Find the order of $(1 \ 2 \ 3 \ 4)(5 \ 6 \ 7)$.

$lcm(4,3)=12$

**Exercise 2.5.26.** Find the order of $(1 \ 2)(3 \ 4 \ 5 \ 6)$.

$lcm(2,4)=4$

## Transpositions and Parity

**Definition 2.5.27.** A **transposition** is a cycle of length 2, i.e., a permutation $(i \ j)$ that swaps $i$ and $j$ and fixes all other elements.

**Theorem 2.5.28.** Every permutation can be written as a product of transpositions.

$Proof:$
By Theorem 2.5.16, every permutation can be written uniquely (up to order) as a product of disjoint cycles.
By exercise 2.521, for an arbitrary cycle: $(a_1 \ a_2 \ \cdots \ a_k) = (a_1 \ a_k)(a_1 \ a_{k-1}) \cdots (a_1 \ a_2)$. that is,
every cycle can be written as a product of transposition.
Therefore, every permutation can be written as a product of transposition.

**Example 2.5.29.** $(1 \ 2 \ 3 \ 4) = (1 \ 4)(1 \ 3)(1 \ 2)$.

**Definition 2.5.30.** A permutation is **even** if it can be expressed as a product of an even number of transpositions. It is **odd** if it can be expressed as a product of an odd number of transpositions.

~={red}**Theorem 2.5.31 (Well-Definedness).** No permutation can be both even and odd.=~

**Theorem 2.5.32.** A cycle of length $k$ is even iff $k$ is odd. That is:
- A cycle of odd length is even.
- A cycle of even length is odd.

$Proof:$
By exercise 2.521, for an arbitrary cycle: $(a_1 \ a_2 \ \cdots \ a_k) = (a_1 \ a_k)(a_1 \ a_{k-1}) \cdots (a_1 \ a_2)$. 
Suppose $k$ is odd, then there are $k-1$ (even) transpositions on the right hand side, i.e. this cycle is even.
Suppose this cycle is even, then written in this form, then by definition 2.5.30. $k-1$ is even, which implies $k$ is odd. Therefore this cycle is of odd length.  
Thus, a cycle of length $k$ is even iff $k$ is odd.

**Example 2.5.33.** $(1 \ 2 \ 3)$ is even (product of 2 transpositions). $(1 \ 2 \ 3 \ 4)$ is odd (product of 3 transpositions).

## Generators of $S_n$  

**Theorem 2.5.48.** $S_n$ is generated by the set of all transpositions. (Definition: A group is generated by a set if all the elements in the group can be written as the product of the elements of the set )

$Proof:$
Since by Theorem 2.5.28, all the elements in $S_{n}$ can be written into the product of transpositions. $S_n$ is generated by the set of all transpositions.

**Theorem 2.5.49.** $S_n$ is generated by $\{(1 \ 2), (1 \ 3), \ldots, (1 \ n)\}$.

$Proof:$
 By Theorem 2.5.48, to prove this theorem we only need to prove that  $\{(1 \ 2), (1 \ 3), \ldots, (1 \ n)\}$can generate all transpositions. 
 For all transpositions like $(i,j), i\neq j; i,j\in \mathbb{Z};1\leq i,j\leq n$.
 Notice: $(1,i)(1,j)(1,i)=(i,j)$ while $(1,i),(1,j)$ are in the set.
 Therefore, all transpositions can be generated by this set.
 Given $S_n$ is generated by the set of all transpositions, $S_n$ is generated by $\{(1 \ 2), (1 \ 3), \ldots, (1 \ n)\}$.
