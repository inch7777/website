# Media folder

Drop image, video, or audio files anywhere in this folder. Nested folders work too.

Supported images: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`, `.gif`, `.svg`  
Supported videos: `.mp4`, `.m4v`, `.webm`, `.ogv`  
Supported audio: `.mp3`, `.m4a`, `.wav`, `.ogg`, `.oga`, `.flac`

The filename becomes the caption. Use words separated by hyphens or underscores:

`evening-in-flekke.jpg` → “Evening in flekke”

An optional date prefix sorts dated files newest-first and adds the date to the caption:

`2026-09-18-evening-in-flekke.jpg`

For a video called `interview.mp4`, optional sidecar files are detected automatically:

- `interview.poster.jpg` — poster image
- `interview.vtt` — English captions
